# XCPC Board

XCPC Board 是给 ICPC / CCPC 队伍做 VP（虚拟参赛）的本地榜单。它按比赛时间重放历史队伍的逐次提交，并把本队在 QOJ 的提交放进同一张榜单。支持封榜和揭榜、局域网看榜、会话归档和赛后分析。

## 快速开始

在 GitHub 点 **Code → Download ZIP**，把压缩包解压到一个固定目录。主机需要安装 **Python 3.10 或以上**，并能在终端运行 `python --version`（Windows）或 `python3 --version`（Ubuntu）。

### 1. 加载 QOJ 浏览器扩展

1. Edge 打开 `edge://extensions/`，Chrome 或 Chromium 打开 `chrome://extensions/`。
2. 开启 **开发人员模式**，点击 **加载解压缩的扩展**，选择项目里的 [`qoj-bridge`](qoj-bridge/) 文件夹，也就是包含 `manifest.json` 的那一层。
3. 在扩展列表里确认已启用 **XCPC VP QOJ 同步**。同一浏览器初次安装时做一次即可，之后直接启动榜单。

### 2. 启动榜单服务

#### Windows

在文件资源管理器里右键 [`start-silent.ps1`](start-silent.ps1)，选择 **使用 PowerShell 运行**。服务就绪后启动窗口会结束，榜单继续在后台运行。要停止时，同样右键 [`stop-silent.ps1`](stop-silent.ps1) 并选择 **使用 PowerShell 运行**。

#### Ubuntu / WSL

在项目目录打开终端，运行 [`start-ubuntu.sh`](start-ubuntu.sh)。保持终端打开，按 `Ctrl+C` 停止服务。

```bash
bash start-ubuntu.sh
```

### 3. 打开榜单并连接扩展

用刚才安装扩展的浏览器打开 [http://127.0.0.1:8770/](http://127.0.0.1:8770/)，并在同一浏览器登录 QOJ。打开扩展弹窗，确认「榜单主机地址」是 `http://127.0.0.1:8770`，点击 **保存并连接**。QOJ 用户名会自动识别，识别失败时再手动填写。做 VP 时保持主机的榜单页打开。

## 开一场 VP

1. 在榜单准备页的「历史比赛」选择并下载与 QOJ 对应的比赛，填写 QOJ 比赛链接，设置队名和赛制。
2. 在 QOJ 完成 **Start → Finish**，然后在榜单点 **连接当前 QOJ VP**。也可以先在榜单点 **等待 QOJ 开始**，识别到倒计时后会自动进入榜单。手动模式按北京时间填写 QOJ 实际开赛时间。
3. 比赛结束后，主机公布最终榜单，再到 **Analysis** 看本队排名轨迹和逐题数据。归档当前比赛后即可准备下一场。

第一次使用也可以先熟悉导入流程。在「历史比赛」展开 **导入比赛数据**，选择 [示例 JSON](examples/contest-replay.json)，点击 **检查数据 → 导入并选择**。示例是一道题的虚构历史记录。

扩展沿用浏览器当前的 QOJ 登录会话。遇到 QOJ 登录失效或需要交互的安全验证时，请在同一浏览器完成操作。Submit 和源码查看的细节见 [提交与源码查看](SUBMIT.md)。

## 给队友看榜

上述启动脚本默认开启局域网访问。队友连接同一个受信任的局域网，用浏览器打开主机准备页 **队友访问** 里显示的地址。Ubuntu 的终端也会打印该地址。只看榜的队友无需安装扩展或下载项目。

主机更换网络后，准备页会重新检测局域网地址。请把「队友访问」中更新后的链接发给队友。主机同时连接 Wi-Fi、网线或 VPN 时，选与队友处于同一网络的地址。

队友把榜单切到后台时，网页会暂停自动读取和重绘。回到前台后，同一次请求会同步主机时间、当前比赛和本队提交。榜单会根据队伍数和题目数控制可见行范围，大榜单的计分分批执行。历史比赛数据使用压缩传输，以减少加载和切回页面时的卡顿。

主机在准备页的 **队友访问** 中决定是否开放更多功能。三个开关默认关闭。

| 开关 | 队友可使用的功能 |
| --- | --- |
| 开放 Home | 查看本队成绩、提交记录，以及当前比赛的提交源码。 |
| 开放 Analysis | 最终榜单公布后查看赛后分析。 |
| 允许提交代码 | 通过主机扩展，以主机登录的 QOJ 账号提交代码。同时开放 Home。 |

如果队友希望把自己在 QOJ 网页上的提交汇入同一场 VP，可在自己的浏览器安装扩展，登录自己的 QOJ 账号，填写主机的局域网地址，并保持 QOJ 页面打开。

## 数据和升级

下载和导入的比赛、VP 会话、历史记录及提交源码存放在本地 `data/`，运行时按需创建。要升级或换电脑时，先停止服务，备份 `data/`，再把它复制到新的项目目录。升级后重启服务、重新加载浏览器扩展，并刷新榜单和 QOJ 页面。

默认端口是 `8770`。自定义端口时，Windows 启动脚本使用 `-Port 8870`，Ubuntu 启动脚本使用 `--port 8870`，并相应修改浏览器与扩展中的地址。后台启动、自定义端口和 WSL 网络设置见 [启动方式与 Ubuntu / WSL 手册](UBUNTU.md)。

## 项目结构

| 路径 | 用途 |
| --- | --- |
| `server.py`、`contest_formats.py`、`stable_clock.py` | 本地服务、比赛数据适配和校时 |
| `static/` | 榜单页面 |
| `qoj-bridge/` | Chrome、Edge 和 Chromium 的 QOJ 扩展 |
| `examples/` | 用于练习导入的虚构比赛 |
| `tests/` | 可在项目根目录使用 Node.js 运行的验证脚本 |

例如，运行 `node tests/verify-scoring.cjs` 检查计分规则，运行 `node tests/verify-vp-start.cjs` 检查 VP 起点识别。日常使用榜单只需 Python 和浏览器。
