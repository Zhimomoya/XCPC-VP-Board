# XCPC Board

XCPC Board 是给 ICPC / CCPC 队伍做 VP（虚拟参赛）的本地榜单。它按比赛时间重放历史队伍的逐次提交，并把本队在 QOJ 的提交放进同一张榜单。支持封榜和揭榜、局域网看榜、会话归档和赛后分析。

## 快速开始

1. 下载并解压项目。主机需要 **Python 3.10 或以上**和现代浏览器，直接使用 Python 标准库运行。
2. 打开项目目录，在终端运行下方对应系统的命令。
3. 打开 [http://127.0.0.1:8770/](http://127.0.0.1:8770/)。按 `Ctrl+C` 停止服务。

**Windows**

```powershell
python server.py
```

**Ubuntu / WSL**

```bash
python3 server.py
```

第一次使用时，可以在准备页的「历史比赛」选择一场比赛并下载数据。也可以展开 **导入比赛数据**，选择 [示例 JSON](examples/contest-replay.json)，点击 **检查数据 → 导入并选择**。示例是一道题的虚构历史记录，可用来熟悉导入流程。开一场 VP 时，请选用与 QOJ 比赛对应的历史数据。

## 开一场 VP

1. 在 Chrome、Edge 或 Chromium 的扩展管理页开启开发者模式，选择「加载已解压的扩展程序」，加载项目中的 `qoj-bridge/`。
2. 在扩展弹窗中填写 `http://127.0.0.1:8770`。在同一浏览器登录 QOJ，并保持主机的榜单页打开。
3. 在榜单准备页选择历史比赛，填写对应的 QOJ 比赛链接，设置队名和赛制。
4. 在 QOJ 完成 **Start → Finish**，再用榜单识别的 VP 起点连接比赛。也可以选择手动输入 QOJ 实际开赛时间，按北京时间填写。
5. 比赛结束后，主机公布最终榜单，再到 **Analysis** 看本队排名轨迹和逐题数据。归档当前比赛后即可准备下一场。

扩展沿用浏览器当前的 QOJ 登录会话。遇到 QOJ 登录失效或需要交互的安全验证时，请在同一浏览器完成操作。Submit 和源码查看的细节见 [提交与源码查看](SUBMIT.md)。

## 给队友看榜

需要共享时，在启动命令末尾加 `--lan`。队友连接同一受信任的局域网，打开终端打印的局域网地址。只看榜的队友直接用浏览器即可。服务的使用范围为本机和受信任的局域网。

主机在准备页的 **队友访问** 中决定是否开放更多功能。三个开关默认关闭。

| 开关 | 队友可使用的功能 |
| --- | --- |
| 开放 Home | 查看本队成绩、提交记录，以及当前比赛的提交源码。 |
| 开放 Analysis | 最终榜单公布后查看赛后分析。 |
| 允许提交代码 | 通过主机扩展，以主机登录的 QOJ 账号提交代码。同时开放 Home。 |

如果队友希望把自己在 QOJ 网页上的提交汇入同一场 VP，可在自己的浏览器安装扩展，登录自己的 QOJ 账号，填写主机的局域网地址，并保持 QOJ 页面打开。

## 数据和升级

下载和导入的比赛、VP 会话、历史记录及提交源码存放在本地 `data/`，运行时按需创建。要升级或换电脑时，先停止服务，备份 `data/`，再把它复制到新的项目目录。升级后重启服务、重新加载浏览器扩展，并刷新榜单和 QOJ 页面。

默认端口是 `8770`。可用 `--port 8870` 修改端口，并相应修改浏览器与扩展中的地址。后台启动、Ubuntu 和 WSL 网络设置见 [Ubuntu / WSL 手册](UBUNTU.md)。

## 项目结构

| 路径 | 用途 |
| --- | --- |
| `server.py`、`contest_formats.py`、`stable_clock.py` | 本地服务、比赛数据适配和校时 |
| `static/` | 榜单页面 |
| `qoj-bridge/` | Chrome、Edge 和 Chromium 的 QOJ 扩展 |
| `examples/` | 用于练习导入的虚构比赛 |
| `tests/` | 可在项目根目录使用 Node.js 运行的验证脚本 |

例如，运行 `node tests/verify-scoring.cjs` 检查计分规则，运行 `node tests/verify-vp-start.cjs` 检查 VP 起点识别。日常使用榜单只需 Python 和浏览器。
